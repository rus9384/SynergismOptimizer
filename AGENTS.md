## General rules
- HTML and CSS properties and values should be written in kebab-case.
- Use `Math.clamp(value, min, max)` (defined in utilities.ts) when a numeric value has to be clamped.
- Use `DOMCacheGetOrSet(id)` instead of getting values from DOM each time.
- Optimize code for performance.
